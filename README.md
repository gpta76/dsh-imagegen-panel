# AI 生图 · imagegen-panel

在 DeepSeek Harness 侧边栏里直接调 ChatGPT 出图：写提示词、选尺寸、挂参考图，结果按时间戳存进你的项目目录，长期做角色资产不用来回切网页。

面向漫剧 / 短剧的角色资产流程：先出一张**正面全身锚点**，再把它当参考图派生三视图、头部特写、侧面、背面和细节图，人物不容易跑形。

## 功能

- **侧边栏常驻**：左侧栏「AI 生图」一个图标，随时点开，不用开新窗口。
- **双通道**
  - OpenAI 兼容中转：`gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gpt-image-1`、`gpt-image-1-mini`、`dall-e-3`，以及中转商支持的任何图像模型。
  - 火山方舟 Seedream：`doubao-seedream-4-0-250828`，国内直连、按量计费。
- **模型实时列表**：从服务端 `/v1/models` 拉取（某中转实测 285 个），支持搜索选择；拉取失败时回落到 5 个内置常用型号。
- **尺寸自由**：比例预设 + 自定义 `宽×高`。已实测 `gpt-image-2.6-flare` 接受任意尺寸，1152×1536 会原样返回。
- **模板 + 尺寸联动**：点「角色档案板」自动切 3:4，点「三视图」自动切 3:2。
- **参考图**：最多 6 张、单张 ≤12MB，走 `POST /v1/images/edits`，用于跨图锁人。
- **结果可追溯**：每张图旁边一份同名 `.json`，记录提示词、模型、实际像素、质量、参考图数量、生成时间。
- **Key 不落页面**：密钥只存宿主机，前端只显示尾 4 位。

## 安装

市场安装：在「插件市场」搜索「AI 生图」→ 安装 → 刷新页面。

本地安装（开发）：

```bash
# 在 DSH 的插件管理里，目标填这个包目录的绝对路径
plugin_manager install_bundle target=<repo>/imagegen-panel
```

装完**重启一次 DeepSeek Harness**（宿主代码不会热加载），再刷新页面。

## 快速开始

1. **准备通道**：任选其一
   - OpenAI 兼容中转：到你的中转商注册、充值、建一个 API 令牌，拿到 `sk-...` 和 Base URL（通常是 `https://xxx/v1`）。
   - 火山方舟：开通 Seedream，拿 Ark 的 API Key 与 `https://ark.cn-beijing.volces.com/api/v3`。
2. **填设置**：侧边栏「AI 生图」→ 右上「设置」→ 点上方通道 chip 预填 → 粘贴 Key → 保存 → **测试连接**。
3. **出第一张图**：点「正面全身（锚点）」模板 → 改成你的角色描述 → 生成。

> Key 只在你自己机器上，面板不会把它写进日志、也不会回传到页面。

## 设置项

| 项 | 说明 |
|---|---|
| 通道 | 「OpenAI 兼容（中转）」或「火山方舟 Seedream」，只影响预填值，字段仍可手改 |
| Base URL | 到 `/v1` 为止，例如 `https://api.gpt.ge/v1`；缺 `/v1` 会自动补 |
| API Key | `sk-...`，保存后界面只显示尾 4 位，可随时「清空」 |
| 模型 | 可从服务端列表挑，也可手填任意模型 id |
| 尺寸 | 下拉预设或直接填 `宽x高`；填错自动退回 `auto` |
| 质量 | `low` / `medium` / `high`，只对 `gpt-image-*` 生效 |
| 背景 | `auto` / `opaque` / `transparent` |
| 输出目录 | 默认 `~/dsh-imagegen`，建议改成项目里的 `refs/生成图` |

## 尺寸建议

| 用途 | 比例 | 尺寸 |
|---|---|---|
| 表情 / 细节特写 | 1:1 | 1024×1024 |
| 角色档案板 | 3:4 | 1152×1536 |
| 竖版全身（锚点） | 2:3 | 1024×1536 |
| 半身 / 头像 | 4:5 | 1024×1280 |
| 三视图横排 | 3:2 | 1536×1024 |
| 场景 / 封面 | 16:9 | 1536×864 |
| 手机竖屏 | 9:16 | 864×1536 |

## 输出

```
<输出目录>/
  20261108-011440-角色档案板-苏念.png
  20261108-011440-角色档案板-苏念.png.json
```

`.json` 示例：

```json
{
  "name": "20261108-011440-角色档案板-苏念.png",
  "prompt": "……",
  "model": "gpt-image-2.6-flare",
  "size": "1152x1536",
  "requestedSize": "1152x1536",
  "quality": "high",
  "referenceCount": 0,
  "createdAt": "2026-11-08T01:14:40.000Z"
}
```

「最近生成」只读这个目录，所以你在外面手动拷进来的图也会出现在面板里。

## 隐私与安全

- 提示词与参考图会发送到**你自己填的 Base URL**，面板本身不带任何中转或遥测。
- 密钥以 0600 权限写在 `~/.dsh/plugin-data/imagegen-panel.json`，不进仓库、不进对话记录、不回传前端。
- 生成图只写你指定的输出目录；插件不会删你的文件。

## 常见问题

**401 / 403**：Key 错、过期，或令牌分组不在 `default`。到中转控制台确认令牌仍然有效、分组选中了通用渠道。

**429 / 余额不足**：账户余额或令牌额度用完了。

**卡很久没反应**：`high` 质量单张常要 30–120 秒，超时上限 240 秒；网络抖动直接重试。

**尺寸被改回去了**：部分中转会把不支持的尺寸吸附到最近档位，`.json` 里的 `size` 记录的是**实际**像素，可据此判断。

**中文文字乱码 / 错字**：图像模型对文字仍是概率生成，短标题命中率高，长段落建议拆成多次或后期排版。

**面板不显示**：装完要重启宿主并刷新页面；浏览器缓存旧 bundle 时按 Ctrl+R。

## 卸载

市场里卸载即可。以下数据**不会自动删除**，按需手动清理：

- 配置与密钥：`~/.dsh/plugin-data/imagegen-panel.json`
- 生成图：你设置的输出目录

## 开发

```bash
node --check index.js   # 宿主：导出 inject/apply，注册 webServer 路由与 tools
node --check client.js  # 前端：window.__ModuleLoader__.load({ id, factory })
```

- 宿主路由前缀 `/imagegen`：`state` / `settings` / `test` / `models` / `generate` / `gallery` / `file` / `reveal`。
- 前端纯 React（`createElement`），样式全用 `--dsw-alias-*` 主题变量，跟随明暗主题。
- 宿主还注册了工具 `imagegen_generate`，可在对话里直接调用同一通道。
