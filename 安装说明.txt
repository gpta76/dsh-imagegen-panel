DeepSeek Harness 生图插件 · 安装与使用说明
dsh-imagegen-panel v1.0.0（MIT 开源，免费）

================================================================
一、这是什么
================================================================
在 DSH 左侧边栏加一个「AI 生图」页面，用你自己配置的 OpenAI 兼容通道
（gpt-image-2.6-flare / gpt-image-2.6-sunburst / gpt-image-1 等）出图，
适合角色资产、漫剧人物图、角色档案板这类工作。

插件本身不要钱，也不带你任何额度：出图花的是你自己在中转站账户里的钱。

================================================================
二、装之前准备两样东西
================================================================
1) 一个能正常用的 DeepSeek Harness（DSH）。
   侧边栏能聊天、能开插件页就行。

2) 一个能出图的 OpenAI 兼容 API Key。
   面板默认按 gpt.ge 的格式预填：Base URL = https://api.gpt.ge/v1
   流程：注册 → 充值（支付宝/微信，1 美元约 1.5~2.5 元）→「API 令牌」建一个 Key。
   用别家（官方、其它中转站）也行，把 Base URL 改成对应地址（一般以 /v1 结尾）。

   Key 只存在你自己电脑上：~/.dsh/plugin-data/imagegen-panel.json
   面板不会把完整 Key 显示出来，只显示尾号。

================================================================
三、安装（3 步，约 3 分钟）
================================================================
第 1 步：解压到一个固定位置
  - 解压这个 zip。确认解压出来的这一层里，直接就能看到这三个文件：
      package.json    index.js    client.js
    如果外面还多套了一层文件夹，就进到里面那一层。
  - 放到不会被清理、不会被移动的地方，例如：
      D:\dsh-plugins\dsh-imagegen-panel
    不要放桌面、下载目录、临时目录。
    原因：DSH 是「链接」到这个目录来加载插件的，挪走或删掉，插件就失效。

第 2 步：让 DSH 里的 AI 帮你装
  - 打开 DSH，随便开一个会话，把下面这句话发给 AI（路径换成你自己的）：
      安装本地插件，目录是 D:\dsh-plugins\dsh-imagegen-panel
  - AI 会调用插件管理工具完成安装，看到「已启用 / enabled」就成了。
  - 如果 AI 说找不到目录，就把路径里的反斜杠原样复制，别用中文引号。

第 3 步：完全重启 DSH（这步不能省）
  - 连托盘/后台的 DSH 一起退出，再重新打开。
  - 宿主端代码不热加载，不重启侧边栏不会出现新图标。

================================================================
四、第一次使用（4 步）
================================================================
1) 左侧边栏点「AI 生图」（在 GitHub 下面一点）。

2) 右上角「设置」，确认这几项：
   通道        OpenAI 兼容（中转）
   Base URL    https://api.gpt.ge/v1
   模型        点「选择模型」→「刷新」→ 选 gpt-image-2.6-flare
               （也可以 gpt-image-2.6-sunburst 或 gpt-image-1）
   API Key     粘贴你的 Key → 保存
   输出目录    默认在 ~/.dsh 下，建议改成你的项目文件夹

3) 点「测试连接」。成功会显示拿到了多少个模型（gpt.ge 一般 285 个左右）。

4) 回到主界面：写提示词（中文完全可用）→ 选尺寸/质量/数量 →「生成图片」。
   出图会存进输出目录，同时出现在下面「最近生成」里，点开可以放大。

================================================================
五、面板怎么用
================================================================
提示词模板（点一下就带好构图和尺寸）：
  正面全身（锚点）  三视图  大头照  侧身  背面  细节/表情  角色档案板

参考图：最多 6 张，单张 ≤12MB。
  做角色一致性时，顺序是：先出「正面全身」当锚点 → 再拿它当参考图派生
  大头照/侧身/背面/细节。这样人物才不跑形。

尺寸：8 档预设 + 可以手动填「宽x高」（3~4 位数字，例如 1152x1536）。
  2:3 用 1024x1536（全身），3:4 用 1152x1536（档案板），4:5 用 1024x1280。

质量：低 / 中 / 高，价格差好几倍。试稿先用「低」，定稿再上「高」。

花费参考：gpt-image-2.6 在 gpt.ge 上大约 $0.05/张（1024~1536 档）。
  以你账户实际扣费为准，面板不代收任何费用。

六、常见问题
================================================================
Q1 侧边栏没有「AI 生图」
   - 没重启 → 完全退出 DSH 再开。
   - 目录被移走/改名 → 插件按原路径链接，路径变了要重装。
   - 还是不行：让 AI 查一下插件列表里有没有 dsh-imagegen-panel。

Q2 测试连接报 401
   - Key 贴错了、多了空格、或者过期了。重新复制一次。

Q3 报 403
   - 这个 Key 没开通该模型，或余额不足。去中转站看「令牌分组」和余额。

Q4 报 429
   - 触发限速，等一两分钟再点。

Q5 生成超时 / 504
   - 尺寸太大或通道排队。换小一点的尺寸，或换个模型重试。

Q6 图里的中文变成乱码/错字
   - 优先用 gpt-image-2.6-flare（对中文最稳）。
   - 提示词里要出现的文字，用引号原样写出来，例如：右上角写「姓名：沈砚」。

Q7 图存在哪
   - 面板右上角「打开文件夹」。每张图下面有「下载」和「复制路径」。

Q8 怎么卸载
   - 在 DSH 插件页禁用/移除 dsh-imagegen-panel，然后删掉解压目录。
   - 设置文件（里面有你的 Key）在 ~/.dsh/plugin-data/imagegen-panel.json，
     不用了这个文件也要删。
   - 已生成的图不会被删，在输出目录里自己处理。

================================================================
七、安全与隐私
================================================================
- Key 只存本机，面板不回显完整 Key。
- 你的提示词和参考图会发到你自己配置的那个通道（中转站），
  涉及私密素材请自行判断。
- 插件无遥测、无后台请求，除了你自己配置的接口地址以外不联系任何服务器。
- 源码：https://github.com/gpta76/dsh-imagegen-panel （MIT）
